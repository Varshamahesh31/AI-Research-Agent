# 🔎 AI Research Agent

An AI-powered research assistant built with **Python, LangChain, and Google Gemini**.

This project uses a LangChain AI agent that can understand a user's query and decide when to use external tools such as **DuckDuckGo Search** and **Wikipedia** to gather information.

---

## ✨ Features

- 🤖 AI-powered research assistant
- 🧠 Uses LangChain agents for intelligent tool selection
- 🔎 Web search using DuckDuckGo
- 📚 Information retrieval using Wikipedia
- 📝 Structured research responses using Pydantic
- 💾 Save research results to a text file
- 🔐 API keys managed securely using environment variables
- ⚡ Powered by Google Gemini

---

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| Python | Programming language |
| LangChain | AI agent framework |
| LangGraph | Agent execution |
| Google Gemini | Large Language Model |
| DuckDuckGo | Web search |
| Wikipedia | Knowledge retrieval |
| Pydantic | Structured output validation |
| python-dotenv | Environment variable management |
